# GTM SDK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn this repo into a versioned, installable SDK that every Tag Manager customer repo imports, so that setting up conversions for a new customer in an existing container is one config file plus one script run.

**Architecture:** Three layers. Layer 1 is the existing `GtmClient` (auth, token persistence, raw `tagmanager_v2` service). Layer 2 adds resource helpers that hide GTM's long resource paths and make tags, triggers, and variables idempotent upserts keyed by name. Layer 3 adds recipes (GA4 event conversion, Google Ads conversion) and an `applyConversions` orchestrator that runs the fixed onboarding sequence: resolve container, create workspace, ensure prerequisites, ensure triggers and tags, check status, create version, optionally publish.

**Tech Stack:** TypeScript 5 (strict, ESM, NodeNext), `googleapis` `tagmanager_v2`, `google-auth-library`, Node 18+, pnpm, vitest, husky + lint-staged.

**Spec:** This document. The "Design" section below records the design discussion from 2026-09-09 and is the spec the tasks implement.

## Global Constraints

- Node `>=18.0.0` (from `package.json` `engines`).
- ESM only: `"type": "module"`, `module: NodeNext`, relative imports inside `src/` use `.js` extensions.
- `strict: true` TypeScript. No `any` in production code; test doubles may cast through `unknown`.
- Package name: `@anthnyalxndr/gtm-sdk`. Repo name stays `gtm_v2`.
- Package manager: pnpm. Do not add `yarn` or `npm` lockfiles.
- Commits use Conventional Commits. No `Co-Authored-By` trailers.
- Never commit `client_secrets.json` or `*.token.json`. Both are gitignored; verify with `git diff --cached` before every commit.
- Every production change ships with a test change.
- Names are the idempotency key for tags, triggers, and variables. Never create a second entity with an existing name.
- Never write to a container's default workspace. All changes go through a named workspace.

## Design

This section is the record of the 2026-09-09 discussion. Read it before any task.

### Why a package

Tag Manager work recurs across customer repos. Each one today would copy the OAuth flow and re-derive the API calls. A single versioned package owns auth and the API surface; customer repos carry only a small config and a script. Bugs get fixed once, and the onboarding sequence becomes reviewable and repeatable.

### Layering

| Layer | Responsibility | Status |
|---|---|---|
| 1. Client | OAuth local-server flow, token persistence and refresh, raw `tagmanager_v2` service, retry and throttling | Exists as `GtmClient`; needs shared credential location, retry, test seam |
| 2. Resource helpers | Resolve `GTM-XXXX` to account/container ids; create-or-reuse workspace; `ensureTag`, `ensureTrigger`, `ensureVariable` upserts by name with fingerprint handling | Not started |
| 3. Recipes | `ga4Event`, `googleAdsConversion`, trigger builders, `applyConversions` orchestrator with `dryRun` and optional publish | Not started |

The raw service stays reachable as an escape hatch so recipes never block a one-off call.

### Shared credentials

Today `GtmClient` defaults both files to the current working directory. That forces re-authorization per repo. The package defaults to `~/.config/gtm-sdk/client_secrets.json` and `~/.config/gtm-sdk/token.json`, overridable by the `GTM_SDK_CONFIG_DIR` environment variable and by constructor options. One Google account holds all customer permissions, so one token serves every repo.

### The onboarding sequence

A customer repo runs:

```ts
import { GtmClient, applyConversions } from "@anthnyalxndr/gtm-sdk";

const client = new GtmClient();
await client.init();

await applyConversions(client, {
  container: "GTM-ABC123",
  workspace: "conversions-2026-09",
  conversions: [
    { kind: "ga4-event", name: "GA4 - generate_lead", event: "generate_lead", measurementId: "G-XXXX", trigger: { type: "formSubmit", formId: "contact" } },
    { kind: "google-ads", name: "Ads - Lead", conversionId: "AW-123", label: "xyz", trigger: { type: "pageview", pathEquals: "/thank-you" } },
  ],
  publish: false,
});
```

`applyConversions` always runs the same sequence:

1. Resolve the public container id to `accounts/{a}/containers/{c}`.
2. Create or reuse the named workspace. Never touch the default workspace.
3. Ensure prerequisites: any constant variables the recipes need.
4. For each conversion: ensure its trigger, then ensure its tag bound to that trigger.
5. Fetch workspace status and fail on merge conflicts.
6. Create a container version from the workspace.
7. Publish only when `publish: true`.

`dryRun: true` prints the planned creates and updates and makes no write calls. It is the review step before touching a live container.

### Pitfalls the design absorbs

- **Fingerprints.** Every update must send the entity's current fingerprint. The `ensure*` helpers fetch, compare, and update in one place so scripts never handle fingerprints.
- **Rate limits.** The Tag Manager API has tight per-user per-minute limits. The client wraps every call with a throttle and retry-with-backoff so scripts do not.
- **Workspace caps.** Standard containers allow only a few concurrent workspaces. Helpers reuse by name; the orchestrator does not create a second workspace with the same name.
- **Built-in variables.** Form and page triggers reference `{{Form ID}}` and `{{Page Path}}`. Page Path is enabled by default; Form ID must be enabled. Task 10 enables required built-ins.
- **Tag parameter keys.** GTM tag templates (`gaawe`, `awct`) take specific parameter keys. The keys used in Tasks 11 and 12 were taken from exported container JSON. If a create call returns a 400 naming a parameter, export a hand-built tag of the same type from the GTM UI and compare keys.

### Distribution

Install from git by tag. It is free and private, and the package has one consumer.

```bash
pnpm add github:anthnyalxndr/gtm_v2#v2.0.0
```

This requires `files: ["dist"]`, an `exports` map, and a `prepare` script that builds on install. Move to GitHub Packages later if version ranges are wanted.

### Relationship to the GTM MCP server

A Google Tag Manager MCP server is already connected in Claude sessions on this machine, with tag, trigger, and workspace tools. That covers ad hoc, agent-driven edits. This package covers repeatable, reviewable, config-driven runs. They complement each other. The recipes layer could later be exposed as its own MCP server.

// src/throttle.ts
export interface RetryOptions {
  maxAttempts?: number;
  baseDelayMs?: number;
}

interface ErrorWithCode {
  code?: number | string;
  response?: { status?: number };
}

export function isRetryable(err: unknown): boolean {
  const e = err as ErrorWithCode;
  const status = Number(e.response?.status ?? e.code);
  return status === 429 || (status >= 500 && status < 600);
}

const sleep = (ms: number): Promise<void> => new Promise((r) => setTimeout(r, ms));

export async function withRetry<T>(fn: () => Promise<T>, opts: RetryOptions = {}): Promise<T> {
  const maxAttempts = opts.maxAttempts ?? 5;
  const baseDelayMs = opts.baseDelayMs ?? 1000;
  let attempt = 0;
  for (;;) {
    attempt += 1;
    try {
      return await fn();
    } catch (err) {
      if (attempt >= maxAttempts || !isRetryable(err)) {
        throw err;
      }
      await sleep(baseDelayMs * 2 ** (attempt - 1));
    }
  }
}

/** Serializes calls and enforces a minimum gap between the start of each. */
export function createLimiter(minIntervalMs: number): <T>(fn: () => Promise<T>) => Promise<T> {
  let chain: Promise<unknown> = Promise.resolve();
  let lastStart = 0;
  return <T>(fn: () => Promise<T>): Promise<T> => {
    const run = chain.then(async () => {
      const wait = lastStart + minIntervalMs - Date.now();
      if (wait > 0) await sleep(wait);
      lastStart = Date.now();
      return fn();
    });
    chain = run.catch(() => undefined);
    return run;
  };
}
```

function collection<T extends { name?: string | null; path?: string | null; fingerprint?: string | null }>(
  state: FakeState,
  store: T[],
  idKey: string,
  kind: string
) {
  return {
    list: async ({ parent }: { parent: string }) => {
      state.calls.push(`${kind}.list`);
      const items = store.filter((e) => e.path?.startsWith(parent + "/"));
      return { data: { [kind]: items } };
    },
    create: async ({ parent, requestBody }: { parent: string; requestBody: T }) => {
      state.calls.push(`${kind}.create`);
      const id = nextId();
      const entity = { ...requestBody, [idKey]: id, path: `${parent}/${kind}/${id}`, fingerprint: "1" } as T;
      store.push(entity);
      return { data: entity };
    },
    update: async ({ path, fingerprint, requestBody }: { path: string; fingerprint?: string; requestBody: T }) => {
      state.calls.push(`${kind}.update`);
      const idx = store.findIndex((e) => e.path === path);
      if (idx < 0) throw Object.assign(new Error("not found"), { code: 404 });
      if (fingerprint !== store[idx].fingerprint) throw Object.assign(new Error("fingerprint mismatch"), { code: 412 });
      const updated = { ...store[idx], ...requestBody, path, fingerprint: String(Number(fingerprint) + 1) } as T;
      store[idx] = updated;
      return { data: updated };
    },
  };
}

// src/resources/workspaces.ts
import type { GtmClient } from "../gtm_v2.js";

export interface WorkspaceRef {
  path: string;
  workspaceId: string;
  name: string;
  created: boolean;
}

export async function ensureWorkspace(client: GtmClient, containerPath: string, name: string): Promise<WorkspaceRef> {
  if (name.trim().toLowerCase() === "default workspace") {
    throw new Error("Refusing to use the Default Workspace. Pass a dedicated workspace name.");
  }
  const service = client.service;
  const ws = service.accounts.containers.workspaces;
  const listRes = await client.call(() => ws.list({ parent: containerPath }));
  const existing = (listRes.data.workspace ?? []).find((w) => w.name === name);
  if (existing?.path && existing.workspaceId) {
    return { path: existing.path, workspaceId: existing.workspaceId, name, created: false };
  }
  const createRes = await client.call(() => ws.create({ parent: containerPath, requestBody: { name } }));
  const created = createRes.data;
  if (!created.path || !created.workspaceId) {
    throw new Error(`Workspace create returned no path for ${name}`);
  }
  return { path: created.path, workspaceId: created.workspaceId, name, created: true };
}

// src/resources/entities.ts
import type { tagmanager_v2 } from "googleapis";
import type { GtmClient } from "../gtm_v2.js";

export type EnsureAction = "created" | "updated" | "unchanged";
export interface EnsureResult<T> {
  entity: T;
  action: EnsureAction;
}

interface Named {
  name?: string | null;
  path?: string | null;
  fingerprint?: string | null;
}

interface Collection<T extends Named> {
  list(params: { parent: string }): Promise<{ data: Record<string, T[] | undefined> }>;
  create(params: { parent: string; requestBody: T }): Promise<{ data: T }>;
  update(params: { path: string; fingerprint?: string; requestBody: T }): Promise<{ data: T }>;
}

/** True when every key in `desired` deep-equals the same key in `existing`. Server-only fields are ignored. */
function matches(existing: unknown, desired: unknown): boolean {
  if (typeof desired !== "object" || desired === null) return existing === desired;
  if (Array.isArray(desired)) {
    return Array.isArray(existing) && existing.length === desired.length && desired.every((d, i) => matches(existing[i], d));
  }
  if (typeof existing !== "object" || existing === null) return false;
  const e = existing as Record<string, unknown>;
  return Object.entries(desired as Record<string, unknown>).every(([k, v]) => matches(e[k], v));
}

async function ensureEntity<T extends Named>(
  client: GtmClient,
  collection: Collection<T>,
  listKey: string,
  workspacePath: string,
  body: T
): Promise<EnsureResult<T>> {
  if (!body.name) {
    throw new Error("Entity body must have a name; name is the idempotency key.");
  }
  const listRes = await client.call(() => collection.list({ parent: workspacePath }));
  const existing = (listRes.data[listKey] ?? []).find((e) => e.name === body.name);
  if (!existing) {
    const created = await client.call(() => collection.create({ parent: workspacePath, requestBody: body }));
    return { entity: created.data, action: "created" };
  }
  if (matches(existing, body)) {
    return { entity: existing, action: "unchanged" };
  }
  if (!existing.path) {
    throw new Error(`Existing ${listKey} "${body.name}" has no path`);
  }
  const updated = await client.call(() =>
    collection.update({ path: existing.path as string, fingerprint: existing.fingerprint ?? undefined, requestBody: body })
  );
  return { entity: updated.data, action: "updated" };
}

export function ensureTag(client: GtmClient, workspacePath: string, body: tagmanager_v2.Schema$Tag) {
  const col = client.service.accounts.containers.workspaces.tags as unknown as Collection<tagmanager_v2.Schema$Tag>;
  return ensureEntity(client, col, "tag", workspacePath, body);
}

export function ensureTrigger(client: GtmClient, workspacePath: string, body: tagmanager_v2.Schema$Trigger) {
  const col = client.service.accounts.containers.workspaces.triggers as unknown as Collection<tagmanager_v2.Schema$Trigger>;
  return ensureEntity(client, col, "trigger", workspacePath, body);
}

export function ensureVariable(client: GtmClient, workspacePath: string, body: tagmanager_v2.Schema$Variable) {
  const col = client.service.accounts.containers.workspaces.variables as unknown as Collection<tagmanager_v2.Schema$Variable>;
  return ensureEntity(client, col, "variable", workspacePath, body);
}

// src/recipes/triggers.ts
import type { tagmanager_v2 } from "googleapis";
import type { GtmClient } from "../gtm_v2.js";
import type { TriggerSpec } from "./types.js";

type Trigger = tagmanager_v2.Schema$Trigger;
type Condition = tagmanager_v2.Schema$Condition;

function condition(type: "equals" | "contains", left: string, right: string): Condition {
  return {
    type,
    parameter: [
      { type: "template", key: "arg0", value: left },
      { type: "template", key: "arg1", value: right },
    ],
  };
}

export function triggerName(spec: TriggerSpec): string {
  switch (spec.type) {
    case "pageview":
      return `Pageview - ${spec.pathEquals ?? spec.pathContains ?? "all"}`;
    case "formSubmit":
      return `Form Submit - ${spec.formId}`;
    case "customEvent":
      return `Custom Event - ${spec.eventName}`;
  }
}

export function triggerSpecToBody(spec: TriggerSpec): Trigger {
  const name = triggerName(spec);
  switch (spec.type) {
    case "pageview": {
      const filter: Condition[] = [];
      if (spec.pathEquals) filter.push(condition("equals", "{{Page Path}}", spec.pathEquals));
      if (spec.pathContains) filter.push(condition("contains", "{{Page Path}}", spec.pathContains));
      return { name, type: "pageview", ...(filter.length ? { filter } : {}) };
    }
    case "formSubmit":
      return {
        name,
        type: "formSubmission",
        filter: [condition("equals", "{{Form ID}}", spec.formId)],
        waitForTags: { type: "boolean", value: "false" },
        checkValidation: { type: "boolean", value: "false" },
      };
    case "customEvent":
      return {
        name,
        type: "customEvent",
        customEventFilter: [condition("equals", "{{_event}}", spec.eventName)],
      };
  }
}

/** Built-in variable types (API enum names) a trigger references. Page Path is on by default in new containers but is ensured anyway. */
export function requiredBuiltIns(spec: TriggerSpec): string[] {
  switch (spec.type) {
    case "pageview":
      return spec.pathEquals || spec.pathContains ? ["pagePath"] : [];
    case "formSubmit":
      return ["formId"];
    case "customEvent":
      return [];
  }
}

export async function ensureBuiltIns(client: GtmClient, workspacePath: string, types: string[]): Promise<void> {
  if (types.length === 0) return;
  const api = client.service.accounts.containers.workspaces.built_in_variables;
  const listRes = await client.call(() => api.list({ parent: workspacePath }));
  const enabled = new Set((listRes.data.builtInVariable ?? []).map((b) => b.type));
  const missing = types.filter((t) => !enabled.has(t));
  if (missing.length === 0) return;
  await client.call(() => api.create({ parent: workspacePath, type: missing }));
}

// src/recipes/apply.ts
import type { GtmClient } from "../gtm_v2.js";
import { resolveContainer } from "../resources/containers.js";
import { ensureWorkspace } from "../resources/workspaces.js";
import { ensureTag, ensureTrigger } from "../resources/entities.js";
import type { EnsureAction } from "../resources/entities.js";
import { ensureBuiltIns, requiredBuiltIns, triggerName, triggerSpecToBody } from "./triggers.js";
import { ga4EventTagBody } from "./ga4.js";
import { googleAdsTagBody } from "./googleAds.js";
import type { ApplyOptions, ApplyResult, ConversionSpec, PlannedChange } from "./types.js";

function toChangeAction(action: EnsureAction): PlannedChange["action"] {
  return action === "created" ? "create" : action === "updated" ? "update" : "unchanged";
}

function tagBodyFor(spec: ConversionSpec, triggerId: string) {
  switch (spec.kind) {
    case "ga4-event":
      return ga4EventTagBody(spec, triggerId);
    case "google-ads":
      return googleAdsTagBody(spec, triggerId);
  }
}

function plan(options: ApplyOptions): PlannedChange[] {
  const changes: PlannedChange[] = [{ kind: "workspace", name: options.workspace, action: "planned" }];
  for (const spec of options.conversions) {
    changes.push({ kind: "trigger", name: triggerName(spec.trigger), action: "planned" });
    changes.push({ kind: "tag", name: spec.name, action: "planned" });
  }
  changes.push({ kind: "version", name: options.versionName ?? options.workspace, action: "planned" });
  if (options.publish) changes.push({ kind: "publish", name: options.versionName ?? options.workspace, action: "planned" });
  return changes;
}

export async function applyConversions(client: GtmClient, options: ApplyOptions): Promise<ApplyResult> {
  const container = await resolveContainer(client, options.container);

  if (options.dryRun) {
    const changes = plan(options);
    for (const c of changes) console.log(`[dry-run] ${c.kind}: ${c.name}`);
    return { workspacePath: `${container.path}/workspaces/<planned>`, changes, published: false };
  }

  const changes: PlannedChange[] = [];
  const ws = await ensureWorkspace(client, container.path, options.workspace);
  changes.push({ kind: "workspace", name: ws.name, action: ws.created ? "create" : "unchanged" });

  const builtIns = [...new Set(options.conversions.flatMap((c) => requiredBuiltIns(c.trigger)))];
  await ensureBuiltIns(client, ws.path, builtIns);
  for (const b of builtIns) changes.push({ kind: "builtIn", name: b, action: "unchanged" });

  for (const spec of options.conversions) {
    const trigger = await ensureTrigger(client, ws.path, triggerSpecToBody(spec.trigger));
    changes.push({ kind: "trigger", name: triggerName(spec.trigger), action: toChangeAction(trigger.action) });
    const triggerId = trigger.entity.triggerId;
    if (!triggerId) throw new Error(`Trigger "${triggerName(spec.trigger)}" has no id`);

    const tag = await ensureTag(client, ws.path, tagBodyFor(spec, triggerId));
    changes.push({ kind: "tag", name: spec.name, action: toChangeAction(tag.action) });
  }

  const wsApi = client.service.accounts.containers.workspaces;
  const status = await client.call(() => wsApi.getStatus({ path: ws.path }));
  const conflicts = status.data.mergeConflict ?? [];
  if (conflicts.length > 0) {
    throw new Error(`Workspace "${ws.name}" has ${conflicts.length} merge conflict(s). Resolve them in the GTM UI before creating a version.`);
  }

  const versionName = options.versionName ?? options.workspace;
  const versionRes = await client.call(() => wsApi.create_version({ path: ws.path, requestBody: { name: versionName } }));
  const versionPath = versionRes.data.containerVersion?.path ?? undefined;
  if (!versionPath) throw new Error("create_version returned no container version path");
  changes.push({ kind: "version", name: versionName, action: "create" });

  let published = false;
  if (options.publish) {
    await client.call(() => client.service.accounts.containers.versions.publish({ path: versionPath }));
    changes.push({ kind: "publish", name: versionName, action: "create" });
    published = true;
  }

  return { workspacePath: ws.path, changes, versionPath, published };
}
```

Note: the built-in `unchanged` entries are not counted in the test's `create` total of 5 (1 workspace + 2 triggers + 2 tags), and the dry-run test expects no `builtIn` entries. Both are honored by the code above.
